## ✨ Key Features

* **Fluid WebGL Backgrounds**  
  Interactive "Molten Metal" and reactive particle systems that respond to cursor movement in real-time. Built from scratch with custom GLSL shaders.

* **Glassmorphism**  
  UI cards are stripped down to 1% opacity (`0.01`). They act as perfectly clear panes of frosted glass (`blur(16px)`), letting the background physics shine through.

* **Motion Choreography**  
  Smooth, scroll-triggered orchestrations cascade elements into view with staggering zero-gravity entrance animations using Framer Motion.

* **Blazing Fast Performance**  
  Zero `.css` files. 100% strictly-typed CSS-in-JS. Optimized with Vite 8 `manualChunks` to split dependencies and guarantee instantaneous load times.
